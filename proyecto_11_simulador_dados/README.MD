# 🎲 Proyecto 11 - Simulador de Lanzamiento de Dados

## ¿Qué es este proyecto?
Un simulador que lanza dados virtuales múltiples veces
y analiza estadísticamente los resultados obtenidos.

## ¿Cuál es su propósito?
Simular experimentos de probabilidad con dados de
diferentes caras (d4, d6, d8, d10, d12, d20) y
visualizar los resultados con gráficas en consola.

## ¿En qué nos ayuda?
- Entender conceptos de probabilidad y estadística
- Practicar bucles, contadores y diccionarios
- Aprender a generar gráficas simples en consola
- Simular situaciones reales de azar y aleatoriedad

## Conceptos de Python practicados
- random.randint()
- Diccionarios como contadores
- Bucles con range()
- Formato de gráficas con caracteres ASCII
- Cálculo de media, moda y frecuencia

## Cómo ejecutarlo
```bash
python simulador_dados.py
```

# ⏱ Proyecto 12 - Reloj de Cuenta Regresiva (Pomodoro)

## ¿Qué es este proyecto?
Un temporizador Pomodoro que alterna sesiones de trabajo
y descanso, con cuenta regresiva visual en consola y
sonido de alerta al terminar cada sesión.

## ¿Cuál es su propósito?
Implementar la técnica Pomodoro: 25 minutos de trabajo
concentrado seguidos de 5 minutos de descanso, ayudando
a mejorar la productividad y el enfoque.

## ¿En qué nos ayuda?
- Aprender a manejar tiempo con time.sleep()
- Practicar bucles con lógica de estados
- Entender cómo limpiar la consola dinámicamente
- Aplicar Python a una herramienta de productividad real

## Conceptos de Python practicados
- time.sleep()
- Bucles con contador regresivo
- os.system() para limpiar consola
- Formato de tiempo mm:ss
- Lógica de estados (trabajo/descanso)

## Cómo ejecutarlo
```bash
python pomodoro.py
```
